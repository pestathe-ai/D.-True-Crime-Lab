# D. True Crime Lab

Misteri che vivono dentro il tuo telefono. Un'app Dom Studio.

## Stagione 1 · Casa
Ti ritrovi con il telefono di Marta, una sconosciuta. Per 7 giorni arrivano
note, email, foto e vocali all'ora in cui "accadono". Le tue risposte, e la
scelta di chiamare o no il contatto **Casa**, portano a uno di **4 finali**.

## Funzioni (v0.1)
- Storia completa di 7 giorni con bivi e 4 finali.
- Notifiche programmate dal telefono, senza server né internet.
- Vocali letti con la sintesi vocale del telefono (voci diverse per personaggio).
- Anteprima veloce: un giorno ogni 3 minuti, per provare tutto in circa 20 minuti.
- Notti tranquille (notifiche tra le 23 e le 8 spostate al mattino), pausa, ricomincia.
- Tutto ciò che arriva è segnato con il simbolo ◆: è finzione.

## Limiti
- Solo Android per ora.
- Le foto sono descritte a parole su riquadri sfocati: niente immagini vere.
- Le voci dipendono dal motore di sintesi installato sul telefono.
- Alcuni telefoni (Xiaomi, Huawei…) possono ritardare o bloccare le notifiche
  delle app in background.
